Default Theme 是 foobar2000 组件 [foo_ui_webview2](https://github.com/NereaFantasia/foo_ui_webview2) 的默认主题，以 AGPL-3.0-only 发布。

Default Theme is the default theme for the foobar2000 component foo_ui_webview2, released under AGPL-3.0-only.

## 安装

需要 foo_ui_webview2 2.0.0 或更高版本，并以独立窗口运行。

1. 从 Releases 下载 `foo-webview-default-theme-<版本>.zip`。
2. 解压到 `<profile>\webview-ui\<模板名>\`，`index.html` 应直接位于该目录。
3. 在 foo_ui_webview2 的首选项页选择该模板，重启 foobar2000。

之后的版本可在主题设置的 **关于** 中开启在线更新。

## Installation

Requires foo_ui_webview2 2.0.0 or later, running as the standalone window.

1. Download `foo-webview-default-theme-<version>.zip` from Releases.
2. Extract it to `<profile>\webview-ui\<template>\` so that `index.html` sits directly in that folder.
3. Select the template on the foo_ui_webview2 preferences page, then restart foobar2000.

Later versions can be installed through online updates under **Settings → About**.
